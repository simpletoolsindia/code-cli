A collection of community projects built on BeastCLI.

:::note
Want to add your BeastCLI related project to this list? Submit a PR.
:::

You can also check out [awesome-beastcli](https://github.com/awesome-beastcli/awesome-beastcli) and [beastcli.cafe](https://beastcli.cafe), a community that aggregates the ecosystem and community.
