Quick Start

Get up and running in under 5 minutes

1

Install BeastCLI

Run the installation command for your platform

curl -fsSL https://beastcli.ai/install | bash
2

Connect Your API Provider

BeastCLI supports 45+ AI providers. Use /connect to add your API key:

# Start BeastCLI
beast

# Inside the TUI, type:
/connect
3

Start Coding

Type your first prompt and let BeastCLI help you code!

# Example prompts:
Fix the login bug in auth.ts
Add TypeScript types to this API
Write tests for the user module
Explain how this regex works

Configuration

Customize BeastCLI to your workflow

Configuration File Locations

Global Config

~/.config/beastcli/tui.json

Project Config

./.beastcli/tui.json

Env Override

BEAST_TUI_CONFIG

Example Configuration

// ~/.config/beastcli/tui.json
{
  "theme": "catppuccin-mocha",
  "animations": true,
  "animations_enabled": true,
  "sound_enabled": false,
  "keybinds": {
    "command_list": "ctrl+k",
    "theme_list": "ctrl+t"
  },
  "experimental": {
    "plan_mode": true
  }
}

Troubleshooting

Common issues and solutions

The beast command may not be in your PATH. Try these solutions:

# Add to your ~/.zshrc or ~/.bashrc
export PATH="$HOME/.local/bin:$PATH"

# Or reinstall with correct PATH
curl -fsSL https://beastcli.ai/install | bash

Your API key may have expired or be incorrect. Reconnect your provider:

# Inside BeastCLI TUI
/connect

# Select the provider
# Enter new API key

Check your permission settings in the config:

# View current permissions
/beast permissions

# Grant specific permission
/beast permit read /path/to/file

Try resetting your theme preference:

# Open theme picker
Ctrl+T

# Select a different theme
# Or check config file for typos
